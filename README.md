# 亲子 AI 创造资料库

属于大人和孩子的 AI 共创资料库：选一个主题，想点子、说清需求，再让 AI 帮忙做成可以试玩的小工具。

线上访问：[Vercel 网站](https://qinzi-ai-lab.vercel.app/)

GitHub Pages：[https://tting1101.github.io/qinzi-ai-lab/](https://tting1101.github.io/qinzi-ai-lab/)

代码仓库：[tting1101/qinzi-ai-lab](https://github.com/tting1101/qinzi-ai-lab)

## 三个创作主题

- **周末做什么转盘**：把全家的活动主意放进转盘，抽出建议后由大人和孩子分别确认。
- **疯狂发明家三转盘**：随机组合物品、能力和用途，由孩子给奇妙发明取名字、讲故事。
- **涂鸦怪兽孵化器**：制作涂鸦展示和装饰改造网页。当前为交互演示，不生成新的 AI 怪兽图片。

网站提供资料和可复制的提示词，三个互动作品需要按照步骤另行制作。参考图是视觉设想，不是运行截图。网站本身不调用 AI API。

## 怎么使用

1. 选主题，按示例准备活动清单、三类词语或一张涂鸦。
2. 在 AI 工具中先发送“需求引导”，回答问题并确认清单。
3. 在同一对话发送“制作提示词”，得到完整的 `index.html`。
4. 保存网页，打开试玩；再按孩子的想法修改。
5. 保留电脑里的作品文件；已有作品网址时，可以用“保存作品链接”存入浏览器。

作品链接只保存在当前浏览器，不上传，不随账号同步，也不会跨设备、跨网址自动跟随。清理浏览器数据可能丢失记录，请自行保留原始作品和网址。

## 文件说明

- `index.html`：页面结构。
- `topics.js`：主题简介、提示词、示例、检查清单和参考图路径。新增主题使用相同结构，卡片和主题数量自动生成。
- `script.js`：主题页面生成、步骤导航、提示词复制、作品链接存档和账号入口。
- `styles.css`：深色太空风格、响应式布局和轻量装饰。
- `images/`：三个主题的 WebP 参考图，使用相对路径。

技术为原生 HTML、CSS 和 JavaScript，不需要安装依赖或运行构建。

## 电脑预览与账号说明

保留文件目录结构，双击 `index.html` 即可阅读资料、复制提示词和保存作品链接。浏览器拒绝自动复制时，页面会提示手动复制。

**Vercel 网站已部署注册和登录后端，账号保存在 Supabase。** GitHub Pages 继续提供静态资料浏览，不运行账号接口。开发电脑保留原 `server.js` 和 `data/` 私有账号文件；它们未迁入云端。运行 `node server.js` 后，可从 `http://127.0.0.1:3000/` 使用原本机账号；`node scripts/start-cloud.cjs` 则使用显式本机私有配置连接云端。直接打开网页文件不能完成账号登录。

本机账号使用每用户随机盐与密码哈希，服务器保存会话 token 的哈希。`data/` 已加入 Git 忽略列表，不上传账号、会话或密码。

## 隐私

孩子仅使用昵称，不填写或分享真名、学校、正脸照片和所在城市。发给 AI 或公开分享作品前，由大人和孩子一起检查。网页不调用 AI API；账号后端所需的 Supabase 服务密钥仅存于本机私有配置及 Vercel Production 服务端变量。环境变量、账号数据和工具缓存已加入忽略列表，不提交到仓库。
