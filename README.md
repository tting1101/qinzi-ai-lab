# 亲子 AI 创造资料库

一个面向家长和孩子的中文静态网页，收集亲子 AI 创作主题、可复制的提示词、操作步骤和原创视觉参考，帮助家庭一起把想象变成作品。

线上访问：https://qinzi-ai-lab.vercel.app/

## 目前的内容

- **周末做什么转盘**：提供制作活动转盘的提示词和亲子协商步骤。
- **疯狂发明家三转盘**：通过物品、能力、用途的组合激发创意。
- **涂鸦怪兽孵化器**：提供把涂鸦变成怪兽展示卡的网页原型提示词。

本网站是创作资料入口。页面中的参考图不是运行截图，三项主题的互动作品需根据提示词另行制作；成果存档目前标为“作品整理中”。网站本身没有接入 AI API。

## 如何使用

1. 打开线上网址，选择感兴趣的创作主题。
2. 复制提示词到自己使用的 AI 编程工具，并参考页面步骤制作作品。
3. 由家长先检查生成结果，再和孩子一起体验、修改和记录。

## 本地查看

下载本仓库后，保留文件目录结构，双击 `index.html` 用浏览器打开即可。不需要安装依赖或运行构建命令。若浏览器限制自动复制，可手动选中提示词复制；也可以使用上方 HTTPS 线上网址。

## 文件说明

- `index.html`：页面内容与主题资料。
- `styles.css`：页面样式和响应式布局。
- `script.js`：主题导航与提示词复制。
- `images/`：三个主题的 WebP 参考图片。

技术：原生 HTML、CSS、JavaScript，无后端、无账号系统。

## 隐私与配置

请仅使用孩子的昵称，不填写或分享真名、学校、正脸照片、城市等身份信息。本项目无需 API 密钥或环境变量；`.gitignore` 已排除 `.env`、常见密钥文件及本地工具配置，后续提交新文件前仍需检查内容。
